**Goal:** Ship v0.2 lifecycle and integration features: zero-downtime key rotation, lifecycle events, stable request context helpers, and supporting docs/tests.

**Architecture:** Extend the existing service/storage/module boundaries without adding direct dependencies on other nestarc packages. Rotation is implemented as an atomic storage operation that inserts a new hashed key and expires the old key; events are best-effort hooks emitted after successful mutations or failed verification. NestJS context helpers remain HTTP-first and read the existing `request.apiKey` property.

**Tech Stack:** TypeScript 5.4, NestJS 10, Prisma-like adapter, Jest, Node 20+.
